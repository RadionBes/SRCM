# ИС «Учёт успеваемости студентов» ГБПОУ ЛРМК

Информационная система для автоматизации учёта успеваемости, ведения групп, расписания и посещаемости студентов Липецкого регионального медицинского колледжа (ЛРМК).

Проект представляет собой REST API на Spring Boot, обеспечивающий взаимодействие с базой данных и предоставляющий интерфейс для фронтенд-части или интеграции с другими сервисами.

## 🛠 Технологии

- **Java 21**
- **Spring Boot 3.x**
- **Spring Data JPA** (Hibernate)
- **PostgreSQL** (или другая СУБД)
- **Liquibase / Flyway** (миграции)
- **Maven / Gradle** (сборка)
- **JUnit 5, Mockito** (тестирование)
- **OpenAPI (Swagger)** (документация API)

## ✅ Реализованный функционал

- Управление студентами (CRUD)
- Управление группами
- Учёт учебных недель
- Формирование расписания
- (добавьте другие эндпоинты, которые уже готовы)
- … *в процессе разработки: журнал оценок, посещаемость, отчёты*
